الأمير نت - HotSpot RouterOS v6
===============================

هذه النسخة هي تطوير كامل للمجلد السابق، مع الحفاظ على الملفات الأساسية وإضافة:
- تصميم عربي حديث ومتكامل لصفحة الدخول والحالة.
- خط Noto Sans Arabic للنصوص وNoto Kufi Arabic للعناوين.
- شعار جديد خاص بالأمير نت في images/logo-amir.svg، مع إبقاء logo.png القديم دون حذف.
- أيقونات وتدرجات وتأثيرات وحالات hover/toast/modal.
- اتصال / واتساب / معلومات كأزرار حقيقية.
- معلومات قابلة للفتح داخل صفحة الدخول.
- سجل الكروت السابقة على نفس الجهاز من أيقونة حقل الكرت.
- جدول أسعار احترافي وصفحة نقاط البيع.
- إشعار اختيار السرعة يظهر فقط بعد اختيار سرعة.
- اختيار السرعة من صفحة الدخول، وتطبيقها عبر وحدة تحكم RouterOS API.
- اختيار سرعة أخرى من صفحة الحالة ثم تطبيقها على مستخدم HotSpot.
- زر إيقاف/تفعيل تحديثات Google Play مع تحكم per-client عبر وحدة التحكم.
- لوحة تحكم كاملة بالأقسام الظاهرة في التصميم المرجعي: معلومات الشبكة، المساحة الإعلانية، السرعات، الباقات، نقاط البيع، الملاحظات، الحفظ والاستيراد والتصدير، واختبار وحدة التحكم.
- سكربتات RouterOS v6 ووثائق عربية.

مهم جداً قبل التشغيل
--------------------
صفحات HotSpot الموجودة على الراوتر هي HTML/JS فقط. RouterOS v6 لا يشغّل PHP داخل مجلد HotSpot ولا يسمح للمتصفح بتنفيذ أوامر /ip hotspot user مباشرة.
لذلك تم وضع وحدة تحكم حقيقية في controller/ تعمل على جهاز داخل الشبكة (Apache/PHP أو XAMPP أو Raspberry Pi أو NAS). هذه الوحدة تتصل بالراوتر عبر RouterOS API وتنفذ تغيير السرعة وإدارة حظر Google Play.

التركيب السريع
--------------
1) ارفع محتويات amir_net_hotspot إلى مجلد HotSpot في WinBox > Files.
2) شغّل scripts/speed-profiles.rsc مرة واحدة لإنشاء ملفات السرعة.
3) عدّل اسم HotSpot profile في scripts/name-only-login.rsc ثم شغّله إذا أردت دخول اسم مستخدم فقط.
4) أنشئ مستخدم API مخصصاً من scripts/controller-user.rsc بعد تغيير كلمة المرور.
5) انسخ controller/config.example.php إلى controller/config.php وعدّل host/user/pass.
6) شغّل controller على جهاز داخل الشبكة عبر PHP/Apache.
7) عدّل secret في config.php. نفس الرمز موجود في js/app.js وjs/admin.js لأنه مفتاح وصول لوحدة التحكم؛ غيّره في الملفات الثلاثة إذا أردت تغييره.
8) ضع رابط وحدة التحكم في لوحة admin.html أو في localStorage عبر إعداد controller.
9) إذا كانت صفحة HotSpot قبل تسجيل الدخول تحتاج الوصول إلى controller، شغّل scripts/controller-walled-garden.rsc بعد تعديل عنوان الخادم والمنفذ.
10) جرّب اختيار سرعة من صفحة الدخول ثم سجّل الدخول. بعد التطبيق سيظهر ملف السرعة في صفحة الحالة.

السرعات المضمنة
----------------
- كرت هوتسبوت: رفع 1M / تنزيل 2M
- سرعة اقتصادية: رفع 256k / تنزيل 512k
- سرعة عادية: رفع 512k / تنزيل 1M
- سرعة متوسطة: رفع 1M / تنزيل 2M
- سرعة عالية: رفع 2M / تنزيل 4M
- سرعة عالية جداً: رفع 2M / تنزيل 6M

ملاحظة RouterOS: rate-limit بصيغة rx/tx؛ rx هو رفع العميل وtx هو تنزيل العميل.

تغيير السرعة أثناء الحالة
--------------------------
status.html يرسل username + profile إلى controller/api.php. الوحدة تعدل profile للمستخدم في /ip hotspot user ثم تفصل الجلسة الحالية حتى يعاد تطبيق rate-limit. بعد ذلك تعيد الصفحة تحميل الحالة ويظهر profile الجديد.

الكروت السابقة
--------------
يتم حفظ آخر 8 أرقام كروت على الجهاز نفسه فقط باستخدام localStorage. لا يتم إرسال سجل الكروت إلى الراوتر.

تحديثات Google Play
-------------------
الزر في صفحة الدخول والحالة يرسل IP العميل إلى وحدة التحكم. عند الإيقاف، تقوم الوحدة بحل مجموعة من نطاقات Google Play الحالية ووضع عناوينها في address-list ثم إضافة قاعدة forward خاصة بعنوان العميل. عند التفعيل تزال القاعدة.
هذه آلية عملية للحالات الشائعة، لكنها ليست ضماناً مطلقاً ضد DoH/DoT أو نطاقات CDN متغيرة. كما أن مدة العناوين ساعة ويمكن إعادة تفعيل الحظر عند الحاجة.

تحذير أمني
----------
لا تفتح RouterOS API على الإنترنت العام. استخدم مستخدم API مخصصاً وصلاحيات محدودة، وقصر /ip service api على عنوان خادم وحدة التحكم.


إصلاح توافق صفحة الدخول
----------------------
تم إصلاح مسار الدخول بحيث لا يفشل تسجيل الدخول بسبب تعطل وحدة التحكم الخاصة بتغيير السرعة. يتم إرسال username مع password فارغ، كما هو مطلوب لوضع اسم المستخدم فقط. هذا يتطلب إعداداً مناسباً في HotSpot/User Manager/RADIUS؛ الصفحة وحدها لا تستطيع تغيير سياسة المصادقة على الراوتر. راجع docs/TECHNICAL-NOTES.md وdocs/SETUP-AR.md.
