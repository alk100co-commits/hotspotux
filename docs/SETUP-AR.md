# دليل تشغيل الأمير نت - RouterOS v6

## 1. رفع الصفحة
ارفع محتويات المجلد إلى مجلد HotSpot الذي تستخدمه في الراوتر.

## 2. السرعات
من WinBox > Files ارفع `scripts/speed-profiles.rsc` ثم افتح Terminal والصق محتواه أو شغّله بالطريقة المناسبة لإصدار RouterOS لديك.

الملفات المنشأة:
- AMIR-P-HOTSPOT = 1M/2M
- AMIR-P-ECO = 256k/512k
- AMIR-P-DEFAULT = 512k/1M
- AMIR-P-MEDIUM = 1M/2M
- AMIR-P-HIGH = 2M/4M
- AMIR-P-VERYHIGH = 2M/6M

## 3. الدخول باسم المستخدم فقط
عدّل `hsprof1` داخل `scripts/name-only-login.rsc` إلى اسم HotSpot profile لديك، ثم شغّل الملف.

يجب أن تكون حسابات HotSpot التي تريد دخولها بدون كلمة مرور مهيأة بدون password.

## 4. وحدة التحكم المباشرة
RouterOS v6 لا يشغل PHP داخل HotSpot. شغّل مجلد `controller` على خادم PHP داخل الشبكة.

مثال:
- الراوتر: 192.168.88.1
- خادم PHP: 192.168.88.2
- API: tcp/8728
- endpoint: http://192.168.88.2:8080/api.php

أنشئ مستخدم API مخصصاً ثم قيّد `/ip service api` على عنوان خادم PHP.

## 5. السماح للوحدة قبل الدخول
إذا كانت صفحة login تحتاج إرسال طلب السرعة قبل المصادقة، يجب السماح بعنوان خادم PHP في HotSpot walled-garden. استخدم `scripts/controller-walled-garden.rsc` بعد تعديل العنوان.

## 6. تغيير السرعة
- المستخدم يختار السرعة.
- الصفحة ترسل username + profile إلى controller.
- controller يتصل بالراوتر عبر API.
- يتم تعديل `/ip hotspot user profile`.
- إذا كانت هناك جلسة نشطة، يتم فصلها لإعادة تطبيق السرعة.
- صفحة status تعرض profile الحالي بعد إعادة التحميل.

## 7. Google Play
زر إيقاف التحديثات يضيف حظر forward مخصصاً لعنوان العميل على عناوين Google Play التي تحلها الوحدة لحظة الضغط.

هذا ليس بديلاً عن حل MDM أو إدارة Android كاملة، ولا يمكن ضمانه ضد DoH/DoT أو CDN غير المعروفة.

## 8. لوحة التحكم
لوحة admin.html تحفظ إعداداتها محلياً وتستطيع تصديرها كملف JSON. عند ضبط controller تستطيع أيضاً اختبار الاتصال وإرسال الإعدادات وتنفيذ أوامر Google Play.

## 9. اختبار قبل الاستخدام
اختبر على كرت تجريبي:
1. سرعة عادية.
2. تسجيل دخول.
3. فتح status والتأكد من ظهور profile.
4. تغيير السرعة من status.
5. إعادة تحميل status والتأكد من ظهور السرعة الجديدة.
6. تجربة زر Google Play.
7. تجربة سجل الكروت.
8. تجربة اتصال وواتساب ومعلومات والأسعار ونقاط البيع.


## ملاحظة توافق مهمة
تم تعديل صفحة الدخول بحيث لا تمنع المصادقة إذا تعذّر الوصول إلى وحدة التحكم المسؤولة عن السرعات. تسجيل الدخول نفسه يرسل اسم المستخدم وكلمة مرور فارغة. لذلك يلزم إعداد حساب تجريبي في HotSpot أو User Manager لقبول كلمة مرور فارغة، وضبط `login-by=http-pap` في HotSpot profile. في حال استخدام User Manager/RADIUS، يعتمد قبول كلمة المرور الفارغة على إصدار User Manager وإعدادات الحساب والمصادقة؛ لا توجد صفحة HTML تستطيع فرض ذلك على الخادم. لا تغيّر إعدادات المصادقة على شبكة عاملة قبل الاختبار بحساب تجريبي.
