# لوحة تحكم الأمير نت

اللوحة الآن تشمل الأقسام التالية:

1. معلومات الشبكة.
2. المساحة الإعلانية.
3. خيارات السرعة مع تفعيل/تعطيل وإضافة وحذف وتصدير.
4. الباقات: الاسم والوقت والصلاحية والميجا والسعر.
5. نقاط البيع: الاسم والوصف والهاتف.
6. الملاحظات مع الإضافة والحذف.
7. اختبار وحدة التحكم.
8. إرسال الإعدادات إلى وحدة التحكم.
9. التحكم في Google Play.
10. حفظ واستيراد وتصدير الإعدادات.

الحفظ المحلي يستخدم localStorage حتى لا تعتمد الصفحة على مكتبات خارجية. التحكم الحقيقي في الراوتر يتم من controller/api.php.
